## 1. 三种视角的定义

| 模式 | 名称 | 相机位置 | 朝向 | 缩放 | 边缘转动 |
| --- | --- | --- | --- | --- | --- |
| `third` | 第三人称（默认） | 目标点后方 `distance` | yaw/pitch | ✅ 2.5~10 | ✅ |
| `first` | 降临视角（第一人称） | **头顶 y+1.6** | 直接沿 yaw/pitch 看出去 | ❌ 禁用 | ❌ 禁用 |
| `top` | 俯视建筑 | 拉远到 `distance=16` | pitch 压到 82° | ✅ 2.5~30 | ✅ |

切换方式：**`V` 键循环** `第三人称 → 降临视角 → 俯视建筑 → 第三人称`，并弹出反馈提示。

## 3. 核心实现（`playerController.mjs`）

### 3.1 相机定位按模式分支

```js
const eye = view === 'first'
  ? [player.position[0], player.position[1] + config.firstPersonEyeHeight, player.position[2]]
  : target;
const travel = view === 'first' ? 0 : distance;
const next = { ...pose, position: eye.map((value, i) => value - forward[i] * travel), forward, up: [0, 1, 0] };
```

### 3.2 新模式有各自的俯仰/距离上限

`pitchLimits()` / `distanceLimits()` 取代原先写死的 `config.maxPitch` / `config.maxDistance`：

- `third`：pitch `10°~65°`，distance `2.5~10`
- `top`：pitch `82°~(90°-ε)`，distance `2.5~30`

这样"俯视建筑"能真正俯下去，而回到第三人称时又不会把一个 82° 的相机写进存档。

## 4. 三个必须解决的坑（都踩到了）

### 4.1 【已解决】玩家模型隐藏会被**持久化**

`setActorState({visible})` 在引擎侧**会自动写盘** → [cef_editor_native_api_handlers.cpp:8484-8504](CoronaEngine/src/systems/ui/cef/cef_editor_native_api_handlers.cpp#L8484-L8504)。
进第一人称隐藏模型后，如果不还原，**退出世界再进入玩家会永久消失**。

解决：`hiddenPlayer` 标志位 + 只在**真实状态跳变**时写一次，并且在三个地方强制还原：

| 时机 | 位置 | 原因 |
| --- | --- | --- |
| 重新绑定玩家 | `bindPlayer` | 换世界必经此处 |
| 组件销毁 | `dispose` | 兜底，即使世界已经在关闭 |
| 切回第三人称 | `setView` | 正常路径 |

写入失败时**不翻转标志位**，保证下次仍然尝试还原（fail-safe 方向正确）。

### 4.2 【已解决】第一人称下边缘转动会"自己转"

原有实现里指针停在视口边缘会持续转动视角（`pointer.edgeX * edgeYawSpeed`）。
若在第一人称保留，玩家会被自己的视角甩着转。

解决：`tick` 与 `hasWork` 都跳过 `view === 'first'` 的边缘转动。
顺带修掉一个真实的空转：**边缘指针不再让帧循环空跑**（原先即使不转也会一直调度下一帧）。

### 4.3 【已解决】切换世界后视角不能残留

`bindPlayer` 现在**强制回到 `third`**，并且只在**没有存档可用时**才重新定位。
理由：导航会保存/恢复每个世界的相机，若把第一人称的"眼部机位"存进去，下次进入会得到一个诡异的机位。

## 5. HUD 集成（`StoryWorld.vue`）

- **`V` 键**：走 `onKeyDown` 独立分支，忽略 `repeat`（长按不会连跳三个模式）、忽略 `Ctrl/Alt/Meta`，并 `preventDefault + stopPropagation`
- **操作提示**新增一行 `V 视角 · <当前模式>`，随切换实时更新
- **`viewTick`**：相机控制器是普通对象，`computed` 追踪不到它；用显式 ref 触发提示重算（与任务 2 的 `roleRef` 同一手法）

切换时弹出反馈，例如：`视角：第三人称 → 降临视角（V 键切换）`。
