## 0. 先说结论（三句话）

1. **你要的不是"从零做"，而是"把已有骨架接上"**：小世界（子世界）本身、玩家第三人称控制、动态创建/隐藏/移动模型、相机实时接管，这四件事引擎**已经全部具备并已在用**。
2. **真正缺的东西只有三类**：① 玩家"属性/物品"数据层（所有人共用）；② 引擎侧**没有角色挂点（骨骼插槽）**，装备/手持武器贴不到角色身上；③ 先知交互、小世界内 UI 变化、视角切换这三块**纯前端逻辑，代码里一行都没有**。
3. **44 小时内必须砍范围**：第一人称/俯视角切换、UI 变化、先知交互可以在前端闭环完成（不需要改 C++）；但"装备穿在身上"在当前引擎下**做不干净**，建议这一版降级为"背包内穿戴状态 + 武器以跟随模型表示"。

[story_gameplay.py](CoronaEngine/game/runtime/story_gameplay.py) 里已有一套**很值得抄**的持久化范式：

**请所有人新增数据时沿用这套结构**，不要另起一套 JSON 写法。

## 3. G1 专项：装备到底怎么办（李淳珺需要知道的"硬骨头"）

这是本次任务里**唯一需要技术决策**的地方。三个可选方案：

| 方案 | 做法 | 成本 | 效果 | 建议 |
| --- | --- | --- | --- | --- |
| **A. 加骨骼挂点 C++ API** | 在 `scene_tools` 增加 `attach_actor_to_bone(scene, child, parent, bone, offset)`，底层用 `mechanics` 已解析的 `skeleton.bone_map` 取骨骼世界矩阵 | **高**（改 CEF handler + C++ 绑定 + 构建验证），44 小时内有风险 | 正确、可持续 | ❌ 本版不做 |
| **B. 前端逐帧跟随** | 装备/武器作为独立 actor 创建，每帧由前端把它的 transform 设到玩家手部近似位置 | **中**（纯前端） | 会抖动/穿模，转身时有延迟，但能看 | ⚠️ 降级可用 |
| **C. 只做数据层** | 背包里记录"已穿戴：头盔 X、武器 Y"，**不渲染在角色身上** | **低** | 逻辑完整，视觉缺失 | ✅ **本版推荐** |

**推荐组合：C 为主 + B 只给武器**（玩家手持武器是观感最强的，值得用方案 B 表现）。

**需要李淳珺决策的问题**：这套游戏最终是否必须"装备真实穿在角色身上"？
- 如果**是** → 建议本版先做 C，把 A 排进下一版（需要 1 个 C++ 同学 2~3 天）
- 如果**否** → C 就够了，本版可交付

### 任务 3：视角切换（降临时第一人称 / 俯视角建筑）

**引擎缺什么**：**不缺**。相机 API 完全够用（见 §1.3）。

**怎么做**（改前端相机控制器，不碰 C++）：

1. 在 [playerController.mjs](CoronaEngine/game/frontend/playerController.mjs) 增加 `viewMode` 状态：`'third' | 'first' | 'top'`。
2. 抽出一个 `poseCamera()` 的分支（当前实现 → [playerController.mjs:89-98](CoronaEngine/game/frontend/playerController.mjs#L89-L98)）：
   - **third（现有）**：`position = target - forward * distance`
   - **first（降临）**：`position = [player.x, player.y + eyeHeight, player.z]`，`forward` 取角色朝向，`distance = 0`；
     同时**应隐藏玩家模型**避免穿模（用 `setActorState(..., { visible: false })`，注意它会自动持久化 → [cef_editor_native_api_handlers.cpp:8484-8489](CoronaEngine/src/systems/ui/cef/cef_editor_native_api_handlers.cpp#L8484-L8489)，**所以退出第一人称必须显式设回 `visible: true`，且世界切换前要确保已恢复**）
   - **top（俯视建筑）**：`pitch` 拉到 `maxPitch` 以上（现有上限 65° → [playerController.mjs:8](CoronaEngine/game/frontend/playerController.mjs#L8)，需为新模式放宽到接近 90°），`distance` 增大到 15~25
3. **切换入口**：建议 `V` 键或滚轮 + 修饰键。注意 [StoryWorld.vue:247](CoronaEngine/editor/Frontend/src/views/layout/StoryWorld.vue#L247) 已经拦截了 `Ctrl/Alt/Meta`，纯键位要新增分支。
4. **与相机保存的关系**：`snapshotPose()` → [viewportStoryCamera.js:63-69](CoronaEngine/editor/Frontend/src/utils/viewportStoryCamera.js#L63-L69) 会把当前机位存进场景。

   → **建议：第一人称态不写入持久化**，退出时强制回第三人称再存。这是必须写进验收的一条。

**验收**：三种视角可切换且互不串味；退出世界再进入能恢复上次视角；**任何情况下玩家模型不会永久消失**。
